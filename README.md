# 🎯 Hangman Game

A **command-line Hangman game built with Python** as part of my **CodeAlpha Python Programming Internship**.

The project focuses on applying Python fundamentals to create an interactive word-guessing game, including user input, random word selection, loops, conditional logic, and basic data structures.

## 📌 Features

- 🎮 Interactive command-line gameplay
- 🔤 Random word selection
- ❤️ Limited number of incorrect attempts
- 📝 Displays correctly guessed letters
- 🔎 Tracks previously guessed letters
- ⚠️ Handles repeated and invalid guesses
- 🏆 Displays win or loss results
- 📚 Uses a word list for game vocabulary

## 🎮 How to Play

1. Run the Python program.
2. A hidden word will be selected from the available word list.
3. Guess the word by entering one letter at a time.
4. Correct guesses reveal the letters in their positions.
5. Incorrect guesses reduce the remaining attempts.
6. Guess the complete word before running out of attempts to win.
